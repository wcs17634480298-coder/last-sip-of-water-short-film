## 剧本分镜

0—6秒
黄沙吞没城市。少年抱着半瓶水，冲进废弃诊所。
妹妹躺在病床上，嘴唇干裂。
少年：“水找到了，哥带你回家。”

6—13秒
枪栓响起。一个男人堵住门，枪口指向少年。
男人：“放下。那是我女儿的水。”

13—21秒
少年掏出刀，挡住病床。
少年：“你女儿要活，我妹妹就该死？”
男人看向床上，枪口慢慢垂下。
妹妹轻声：“哥……分她一点吧。”

30—36秒

男人：“带你妹妹走……顺路看看她。”
